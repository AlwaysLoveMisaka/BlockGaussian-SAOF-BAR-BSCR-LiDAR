# Upstream dependency and attribution

The code in this repository extends the workflow of the [official BlockGaussian implementation](https://github.com/SunshineWYC/BlockGaussian):

> Yongchang Wu, Zipeng Qi, Zhenwei Shi, and Zhengxia Zou, “BlockGaussian: Efficient Large-Scale Scene Novel View Synthesis via Adaptive Block-Based Gaussian Splatting,” 2025.

The upstream source and third-party rasterizer/submodules are **not** included here. Users must obtain and comply with their respective terms separately. The `BLOCKGAUSSIAN_ROOT` environment variable points these scripts to an installed upstream-compatible project. This repository does not state or imply that the upstream authors endorse the additional methods.
